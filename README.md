# CápsulaData

Storytelling con tus datos — dashboard económico de Chile y Latinoamérica.

Sitio web estático (HTML/CSS/JS vanilla) con datos macroeconómicos de Chile vs el mundo.
Desplegado en GitHub Pages desde este repositorio.

## Estructura

- `index.html` — Landing page
- `servicios.html` — Servicios
- `lalinea.html` / `lalinea/` — La Línea (dashboard económico)
- `data/` — Datos procesados
- `vendor/` — Librerías third-party
- `build_projects.py` — Script de build
- `logo.png` — Logo

## Despliegue

GitHub Pages sirve directamente desde la rama `main`.
